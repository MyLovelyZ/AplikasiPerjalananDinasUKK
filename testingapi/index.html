2. Tes otomatis semua endpoint

Menjalankan alur lengkap: login tiap role, CRUD admin, lalu satu perjalanan dinas dari pengajuan → persetujuan supervisor → verifikasi anggaran → bayar uang muka → LPJ + upload struk → verifikasi LPJ → pelunasan. Tes membuat pegawai uji baru setiap kali dijalankan, lalu menghapusnya di akhir. Klik baris hasil untuk melihat request & response-nya.

3. Request manual

Klik endpoint untuk mengisi form. Ganti {...} di path dengan ID.

Kalau ada file, body dikirim sebagai multipart/form-data (PUT otomatis jadi POST + _method=PUT).
